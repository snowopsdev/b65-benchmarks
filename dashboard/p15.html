What this is

The local-ai-registry lists a recipe for a card only if a run passes six lab gates: load, chat, reasoning (thinking returned separately, 17 × 23 right), tools (calls the tool and uses the result), context (finds a code planted at 85% of the window) and speed (decode ≥ 15 tok/s over the first 30 s of an uncapped answer). The pre-check runs those gates against our native SYCL build; the registry runs use the pinned official image and write the recipe.
